# Math Operations

Exercise math handlers via markscript function calls.

```markscript
print(sin(1))
print(cos(0))
print(sqrt(16))
print(abs(-42))
print(min(3, 7))
print(max(3, 7))
print(clamp(15, 0, 10))
```

## random

```markscript
print(random(1, 100))
```

## verify

```markscript
print("math_ops: all math handlers executed")
```
