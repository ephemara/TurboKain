# Bench Runner

Mini benchmark runner via markscript handler calls.

```markscript
print(concat("bench", "_", "binary_trees"))
print(concat("bench", "_", "nbody"))
print(concat("bench", "_", "fasta"))
print(concat("bench", "_", "regex"))
print(concat("bench", "_", "mandelbrot"))
print(upper("all_benchmarks_complete"))
```

## verify

```markscript
print("bench_runner: 5 benchmarks orchestrated")
```
